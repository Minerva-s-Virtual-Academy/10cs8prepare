Module 3: Scenario-Based Hardware Architect Questions

Instruction: Read each real-world technical scenario carefully and select the correct answer to analyze system performance and hardware behavior.

Scenario 1: High-Performance Video Rendering

A video editor is working on a 4K project. When opening multiple high-resolution video streams simultaneously, total active memory usage exceeds the computer's 16 GB physical RAM capacity. The system experiences noticeable performance slowdowns, and the storage activity LED stays lit constantly.

Question: What technical process is occurring, and why does system performance degrade?

Scenario 2: Embedded Systems & Power Failure

An engineer is designing a automated traffic light controller. Upon powering on or recovering from a power outage, the system must immediately execute fixed initialization routines stored in firmware without relying on user intervention or lost data.

Question: Which memory component must store these initial bootloader instructions and why?

Scenario 3: System Bus Analysis

During an instruction cycle, the CPU Control Unit sends a signal to read data from a specific memory address in Main Memory (RAM).

Question: Which combination of system bus directions correctly describes this memory access operation?
